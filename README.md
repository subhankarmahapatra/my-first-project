# AI-Powered Career Intelligence & Job Recommendation System

## 📌 Project Overview

The **AI-Powered Career Intelligence & Job Recommendation System** is a Python-based Machine Learning project designed to help students and job seekers identify suitable career opportunities based on their skills, interests, education and experience.

The system analyzes candidate profiles, recommends relevant career paths, identifies missing skills and provides personalized learning roadmaps.

## 🎯 Project Objectives

- Recommend suitable career paths using Artificial Intelligence techniques.
- Analyze candidate skills and interests.
- Identify skill gaps and suggest learning paths.
- Analyze resume text and extract technical skills.
- Match candidate profiles with suitable job roles.
- Estimate indicative salary ranges using Machine Learning.
- Visualize career and job recommendation insights.

## 🚀 Key Features

1. **Career Recommendation System** – Suggests suitable career options.
2. **Resume Analyzer** – Extracts skills from resume text.
3. **Job Recommendation Engine** – Matches candidate skills with job requirements.
4. **Skill Gap Analysis** – Identifies missing technical skills.
5. **Learning Roadmap Generator** – Suggests learning steps for career development.
6. **Salary Prediction** – Estimates salary using Random Forest Regression.
7. **Candidate Segmentation** – Groups candidate profiles using K-Means clustering.
8. **Data Visualization** – Displays analytical charts and insights.
9. **Report Generation** – Exports career recommendations and reports.
