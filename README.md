# Human Emotion Analyzer (Java)

A realistic human‑emotion analyzer built in Java.  
It detects emotions like Happiness, Sadness, Anger, and Fear using weighted NLP logic.

## 🌟 Features
- Deep human vocabulary detection  
- Weighted emotional scoring  
- Sentiment analysis (−100 to +100)  
- Realistic AI‑style empathetic responses  
- Supports words like “overjoyed”, “thrilled”, “proud”, “ecstatic”, etc.

## ⚙️ How to Run
```bash
javac HumanEmotionAnalyzer.java
java HumanEmotionAnalyzer
